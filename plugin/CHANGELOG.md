# dsh-jieqi 变更记录

## 0.8.0 — 2026-10-31

- 整卡又能点了，而且不会误清剪贴板：按下卡片后位移超过 3px 才算拖动，没动就松开仍然是「复制今天的摘要」，圆点还是管置顶/展开。标题旁的徽标会替你说一声「已复制」（约 1.3 秒，读屏同步）。
- 多一行当令养生：卡片正文下面多一行提示，取自内置 skill 的《节气养生速查》（如霜降「燥寒并至，宜平补（山药、栗子），护胃护膝，忌过食辛辣」）。接口在 today 里多返回 `tip`，最多两行，悬停看全文。
- 倒计时精确到小时：不再只写「距立冬 7 天」，而是「距立冬 6 天 17 小时」，悬停给出交节时刻；交节当天改成实时倒计时（「距霜降 交节 43 分钟」），过了点才说「今日几点交节」。
- 系统通知点得动：点通知会抬起窗口、展开卡片，直接看今天的节气。
- 首帧不再空白：把上一次的 today 结果缓存下来，冷启动先画旧数据，接口回来再换新的。
- 顺手修掉自己埋的坑：新加的 `span()` 与进度条里的同名局部变量冲突，交节当天倒计时会抛 ReferenceError；局部变量已改名 `total`。

## 0.7.0 — 2026-10-30

- 收起后的卡片真正藏起来了：除了淡出，还补了 `visibility: hidden`，动画结束才生效，Tab 不再走进一张看不见的卡片里的按钮。打开时卡片是 `role="dialog"` 并带 `aria-label`。
- Esc 现在处处管用：在子页面按 Esc 回主页面，在主页面按 Esc 把卡片收起来（连置顶一起放掉），不用再去点那颗小叉。
- 拖动不再逐帧重渲染：按下时只把「开始搬运」记进 state，之后每个指针事件直接写面板和圆点的 `transform`，松手前一次 React 都不重排。挪窗口顺手了很多。
- 接口挂了也有底：请求 6 秒超时自动放弃，再静默重试两轮，仍不行就用本地天文算出今天；连本地都失败则一分钟后自己再试，不再永久空着一张卡片。
- 只有节气名能复制：整张卡片随手指拖动以后，误触正文就清空剪贴板的概率太高，现在点标题里的「霜降」二字才复制摘要，其余地方按一下只是按一下。
- 第一次见面有引导：初次加载时圆点保持醒目、不进入安静态，卡片底部多一行「拖我走 · 点节气名复制 · Esc 收起」，看过一次就不再出现。
- 无障碍补了三处：提示条是 `role="status"` + `aria-live="polite"`，圆点带 `aria-haspopup`/`aria-expanded`，收起的卡片对读屏隐藏。

## 0.6.0 — 2026-10-30

- 拖动改走合成层：卡片位移不再改 `left/top`，而是一个 `translate3d`，指针移动不再触发布局回流；卡片同时补 `touch-action: none`，触屏上按住正文是拖窗口、不是滚页面。
- 松手有惯性：按松手前约 110ms 的速度给一段最多 170px 的滑行，走 380ms 的 `cubic-bezier(0.16, 0.84, 0.28, 1)` 缓出；滑行途中再按一下会把卡片就地按住。
- 圆点跟随：拖卡片时圆点跟着窗口一起走并缩到 0.72、淡到 0.55，松手落到新位置的上沿或下沿，不再留在原地等你回去找。
- 页签换页有高度过渡：换页时卡片先保持旧高度，两帧后骑到新高度（220ms）并让新内容淡入，页签在长短不一的页面之间不再突兀地跳一下。
- 卡片顶部多一条 26×3 的抽屉把手，暗示整块可以抓；窄窗单行态不显示。
- 尊重 `prefers-reduced-motion`：关掉系统动效时，惯性滑行与高度过渡都直接落位。
## 0.5.0 — 2026-10-30

- 整张卡片都能拖动：按住正文任意处即可带着窗口走，圆点在拖动时淡出、松手后落到卡片上沿（向下展开时落到下沿），不必再精确抓住那颗点。
- 拖卡片时窗口不吸附、不折成边缘标签，松手即停在原地，避免手指还没抬起来窗口就跳走。
- 边缘出窗改成气泡动画：从贴墙那一侧撑开——先横向拉长、纵向压扁、圆角鼓起并轻微失焦，再回弹两次收成卡片；关闭时沿原路缩回墙面。
- 自由态与吸附态各有自己的出泡方向：吸附时从标题栏下沿冒出来，靠下时从卡片底沿向下长出来。
- 贴墙展开时背景多一层 620ms 的径向光晕，强化「从墙里冒出来」的体积感。
- 单击卡片复制摘要、单击圆点置顶/展开、双击或右键复位等原有行为保持不变。
## 0.4.0 — 2026-10-30

- 插件内置 `jieqi` skill（`assets/jieqi/`），宿主通过 `ctx.skills.registerProvider` 注册；安装插件即同时得到卡片与 skill，不需要再手动拷贝到 `~/.agents/skills`。
- skill 正文中的脚本路径在加载时替换为安装目录的绝对路径，模型可直接运行。
- 独立 `skill/jieqi/` 继续保留，供只想装 skill 的人使用。

## 0.3.0 — 2026-10-30

- 算法收敛为单一核心 `lib/astro.mjs`：24 节气、十二消息卦、三伏、数九、干支历都在这里；`jieqi` skill 携带同一份文件。
- 交节时刻加入 ΔT 修正（Espenak–Meeus 分段多项式）；与紫金山天文台公布值差约 2–6 分钟。
- 宿主 `lib/index.js` 重写为薄封装（2.4 KB），新增 `/api/year?year=`；非法日期返回 400 而不是 500。
- 修正两卦爻线：未月遁 `[0,0,1,1,1,1]`、戌月剥 `[0,0,0,0,0,1]`。
- 体验：悬停 120ms 迟滞、每日自动问候一次、交节日聚焦时直接展开、提示权限后才发系统通知、接口失败本地兜底。
- 可达性：圆点 `:focus-visible` 描边、`prefers-reduced-motion` 关闭动画。
