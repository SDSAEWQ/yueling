# dsh-jieqi 变更记录

## 0.3.0 — 2026-10-30

- 算法收敛为单一核心 `lib/astro.mjs`：24 节气、十二消息卦、三伏、数九、干支历都在这里；`jieqi` skill 携带同一份文件。
- 交节时刻加入 ΔT 修正（Espenak–Meeus 分段多项式）；与紫金山天文台公布值差约 2–6 分钟。
- 宿主 `lib/index.js` 重写为薄封装（2.4 KB），新增 `/api/year?year=`；非法日期返回 400 而不是 500。
- 修正两卦爻线：未月遁 `[0,0,1,1,1,1]`、戌月剥 `[0,0,0,0,0,1]`。
- 体验：悬停 120ms 迟滞、每日自动问候一次、交节日聚焦时直接展开、提示权限后才发系统通知、接口失败本地兜底。
- 可达性：圆点 `:focus-visible` 描边、`prefers-reduced-motion` 关闭动画。

## 0.2.0–0.2.6 — 2026-10-29/30

- 十二消息卦（随月建显示爻线，点开读卦辞）、三伏与数九、年表页（3×8、可左右翻年）。
- 可自由拖拽 / 吸附标题栏 / 停靠窗口边缘成半隐藏标签；双击或右键复位；记住上次打开的页面。
- 窄窗单行摘要、`Alt+J` 快捷键、跨日自动换日、七十二候子页。
