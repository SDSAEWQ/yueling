# 节气（jieqi）

用随带脚本按太阳黄经精确求解二十四节气，**不要凭记忆报节气日期**（模型记忆的节气日期经常错一天，交节时刻更不可靠）。

## 用法

在 skill 目录下运行（Windows 上 node 在 PATH 里）：

    node scripts/jieqi.mjs                # 今天的节气
    node scripts/jieqi.mjs 2026-12-22     # 指定日期
    node scripts/jieqi.mjs --json         # 机器可读
    node scripts/jieqi.mjs --year         # 附当年 24 节气全表

输出示例：

    2026-10-30　丙午年 戌月（月建自 寒露）
    当前节气：霜降（2026-10-23 17:39 交节，第 8 天）
    下一个节气：立冬（2026-11-07 17:49，还有 8 天）
    养生：燥寒并至，宜平补（山药、栗子），护胃护膝，忌过食辛辣。

- 当天正好交节时，第二行变为「今日交节：冬至（2026-12-22 04:47）」。
- 年干支严格按立春换年：立春前算上一年（脚本按北京日期比较，立春当天整天算新年）；**跨立春当天**问年干支时，可补一句"命理上以立春交节时刻为界"。
- 月建按节气换月（立春起寅），是命理里的"节气月"，与农历月不同。
- 已做 ΔT 修正（Espenak–Meeus），交节时刻与紫金山天文台公布值差约 2–6 分钟，日期可靠；追到秒级需换 VSOP87。

## 播报风格

- 日常播报控制在 3 行内：日期+干支月建、当前/今日节气、距下一个节气天数，末尾一句养生。
- 用户是道家/中医爱好者：可顺手连到"节气—月建—命理"，但别每次都展开长篇。
- 养生建议只作生活参考，涉及疾病请就医。
